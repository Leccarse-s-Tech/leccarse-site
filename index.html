O que construímos

Código limpo, entrega com prazo e os sócios acompanhando cada etapa do início ao deploy.

> leccarse --listar-servicos

  • Sites e landing pages [destaque]

    HTML semântico, identidade visual própria, layout responsivo e carregamento rápido. Páginas pensadas para aparecer bem no Google e transformar visitas em contatos reais.

  • Sistemas web sob medida [full-stack]

    Back-end, banco de dados e painel administrativo desenhados em torno do seu processo, e não o contrário.

  • APIs e integrações [conectividade]

    Conectamos o seu sistema a pagamentos, planilhas, ERPs e serviços de terceiros via API, sem retrabalho manual.

  • Automação de processos [scripts]

    Rotinas repetitivas viram scripts e fluxos automáticos, com registro de tudo o que foi executado.

  • Treinamento para equipes [autonomia]

    Capacitamos o seu time para operar e evoluir o sistema entregue, com prática em cima do seu próprio projeto.

Landing Page & Conversão

BarbeMan (Barbearia Conceito)

O Desafio

Pequenos negócios locais sofrem com templates genéricos e pesados, perdendo clientes por falta de agilidade e clareza no agendamento.

A Solução

Layout estilo apresentação em tela cheia com carrossel dinâmico, código limpo em HTML5, CSS puro e Vanilla JS, com integração direta ao WhatsApp.

O Impacto

Carregamento ultrarrápido sem dependências externas, navegação intuitiva por gestos/teclado e conversão em 1 clique.

Automação & Finanças

Ranking de Segurança de Ativos (B3)

O Desafio

Acompanhar 45 empresas na Bolsa manualmente exigia horas de cálculo de múltiplos e análise de oscilação semanal em planilhas sujeitas a erros.

A Solução

Rotina em Python consumindo dados via API Brevi, calculando um índice comparativo de estabilidade (P/E + amplitude + posição de 52 semanas) e painel analítico publicado na Vercel.

O Impacto

Processamento instantâneo em segundos com zero esforço manual, oferecendo visão clara e confiável para análise de consistência.

Python API Brevi B3 Lógica Matemática
